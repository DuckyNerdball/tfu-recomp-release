Star Wars: The Force Unleashed - Ultimate Sith Edition (Xbox 360) - PC recompilation, setup package

This package contains no game files and no game program. It builds the game on your PC from your own two
Xbox 360 disc images.

With RecompLauncher: install, give it Disc 1 and Disc 2 on the setup screen, wait for the build, press Play.
By hand:  Prepare.cmd -Disc1:D:\path\disc1.iso -Disc2:D:\path\disc2.iso     then     Play.cmd

Needs: Windows 10/11 x64, a CPU with AVX2, Git, Visual Studio 2022 Build Tools (C++), clang 20 or newer,
about 40 GB free. First setup takes one to two hours.

In game: F9 (or L3+R3 on a controller) opens the cheat menu.
